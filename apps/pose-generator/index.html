Gerador de Poses — IsdetArt

Você nomeia um personagem; a ferramenta lê personalidade e lore e devolve poses que combinam com ele — com o porquê de cada uma e um trecho de prompt pronto pro OpenArt.

API Key

Usada só nesta sessão. Some ao fechar a aba. Obtenha em console.anthropic.com → API Keys.

Personagem
Inclua a obra pra evitar ambiguidade. Toque para testar:
Capitão Yamamoto de Bleach 4º Hokage de Naruto Shippuden Ranger Vermelho de Power Rangers Guts de Berserk
Ajustes (opcional)

O trecho de prompt sai sempre em inglês (formato do OpenArt) e descreve só a pose / linguagem corporal / enquadramento — pra você juntar ao seu prompt de personagem + estilo.
